# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-08-31

- Define the minimal callable/JVP/VJP rule protocol.
- Add allocation-free `ZERO` short-circuit semantics.
- Add identity-based rule registration and stable error types.
- Add scalar gradient conveniences derived from VJP.
- Add dependency-free conformance helpers and full documentation.
